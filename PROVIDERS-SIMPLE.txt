Use this with a fetch tool when you don't have a Bowmark API key.
Call each as bowmark.providers.<provider>.<function>(...) inside a run script.

For full details on each function, see PROVIDERS.md or query the live API:
GET https://api.bowmark.ai/v1/library?query=<site-or-function>
